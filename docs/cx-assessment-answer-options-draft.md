# CX Maturity Assessment: draft answer wording

Draft for team review, not applied to the site. The live assessment still uses the current answers; only the question stems were rewritten.

Goals, from the Part 2 review notes:

1. Trim the level 5 answers to match the other levels (they average 15.4 words; level 4 averages 12.3). The drafts average 12.1 words and each remains a clear step above level 4.
2. Make commercial-only wording work for public-sector and federal respondents (board, revenue, ROI, marketing budgets, compensation, competitive advantage), using "business or mission" where the question rewrites already do.
