# CX Maturity Assessment: answer wording changes

Applied to the live assessment on 2026-11-06, following Lam's direction:

1. Simplify every answer while keeping its meaning.
2. Drop contrast tails ("X, not Y").
3. Use sector-neutral wording, because the assessment never asks which market the respondent is in (no "board", "ROI", "compensation", "competitive advantage", "marketing budgets").

Average length is now 8–11 words per level (level 5 was 15.4). Scoring is unchanged: each answer keeps its level.

Question codes: P = Practitioner track, E = Executive track; a code without a letter is shared by both tracks.

## QA checklist

For each question, read the five new answers in order and check:

- [ ] Each level is clearly a step above the one before it
- [ ] The answer still means the same thing as before
- [ ] It makes sense to a CX practitioner without being overcomplicated
- [ ] No market-specific words, such as "agency" (federal) or "board", "revenue", "ROI" (commercial)
